x86-64 NASM Assembly

This directory documents my journey learning x86-64 assembly language using NASM on Linux.

My goal is to understand how software interacts with the processor, how instructions manipulate registers and memory, and how programs execute at the machine level.

Tools & Environment

- NASM – Netwide Assembler
- GDB – GNU Debugger
- GCC – GNU Compiler Collection

Learning Topics

- Assembly language fundamentals
- x86-64 registers
- Memory addressing
- Data movement and arithmetic instructions
- Conditional and unconditional jumps
- Stack operations and function calls
- Linux system calls
- Program execution and debugging
- ELF executables

Projects

Projects will be added as I progress:

- Arithmetic Calculator
- CGPA Calculator
- Number Guessing Game

Learning Objectives

- Understand CPU instructions and register operations.
- Understand memory addressing and data representation.
- Learn how assembly programs interact with the Linux kernel.
- Develop a foundation in reverse engineering and systems programming.

This repository is part of my long-term journey into systems programming, reverse engineering, and cybersecurity.
